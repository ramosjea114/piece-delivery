Phase 00 — Project Foundation

Role

You are implementing the foundation of a Windows-first, local-only bilingual AI screen translation application.

This application is inspired by the interaction concept of HeyClicky, but it is an independent application. Do not copy HeyClicky’s implementation, branding, assets, proprietary code, or design.

The application translates visible Japanese ↔ English desktop content and eventually displays the translation as a spatially anchored overlay near the original text.

Core Principles

* Windows 10/11 x64.
* Python 3.11+.
* Local-first.
* No cloud OCR.
* No cloud translation.
* No telemetry.
* No analytics.
* No remote screenshot storage.
* No automatic upload of screenshots.
* LLM endpoint must be configurable.
* Initial LLM target: Qwen3:4B.
* LLM communication must support an OpenAI-compatible local HTTP API.
* Architecture must allow Ollama, llama.cpp server, LM Studio, vLLM, or another compatible local server later.
* Do not hard-code credentials.
* Do not download models automatically at runtime.

Initial Technology Stack

Use:

* Python 3.11+
* PySide6
* OpenCV
* NumPy
* mss
* Pillow
* httpx
* PyYAML
* SQLite
* pytest

OCR must be implemented behind an interface so the engine can be replaced later.
