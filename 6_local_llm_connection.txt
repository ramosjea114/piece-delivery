Phase 06 — Local Qwen Connection

Objective

Connect the application to a configurable OpenAI-compatible local LLM endpoint.

Initial model:

qwen3:4b

Possible providers:

* Ollama
* llama.cpp server
* LM Studio
* vLLM
* other OpenAI-compatible local servers

Configuration

Use:

llm:
  base_url: "http://127.0.0.1:11434/v1"
  api_key: ""
  model: "qwen3:4b"
  temperature: 0
  max_tokens: 1000
  timeout: 60

Never hard-code a real API key.

Never commit credentials.

Implement

Create:

translation/
├── llm_client.py
└── translator.py

The client must support:

* configurable endpoint
* configurable API key
* configurable model
* timeout
* HTTP error handling
* connection failure handling
* clean response extraction
